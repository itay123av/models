The problem

Manual verification is a tax on every CS department.

Automata are drawn by hand — on exams, whiteboards, and napkins. Testing them shouldn't be.

The status quo

Grading by finger-tracing

TAs trace every input through every transition of every submission — hundreds of times per exam, at 2am, with a red pen.

Rebuilding machines in legacy tools

Verifying a single diagram means re-drawing it node-by-node in JFLAP before you can run anything. Multiply by 300 submissions.

Silent transcription errors

One mislabeled edge and a correct machine gets marked wrong — or a wrong protocol ships to firmware.

With AutomataVision

Snap → parse → run

Photograph any drawing — notebook, whiteboard, exam sheet. A validated, executable model appears in under five seconds.

Test like a compiler

Feed it 01101 — or a whole test suite. Watch acceptance paths light up state by state, step by step.

Verify at cohort scale

Batch-scan every submission and auto-check language equivalence against your reference machine — via dashboard or API.

Capabilities

Everything between the napkin and the grade book.

A complete pipeline: perception, reconstruction, simulation, verification, export.

State-of-the-Art Vision AI

Detection models trained on 2M+ real and synthetic diagrams recognize states, accepting rings, initial arrows, curved and crossing edges, multi-symbol labels like 0,1, and ε-transitions — through coffee stains, eraser ghosts, and whiteboard glare.

Instant Input Simulation

Run any string on the reconstructed machine. Step forward and back, set breakpoints on states, and inspect the full acceptance trace — the rigor of a debugger, applied to theory.

q₀ —0→ q₁ —1→ q₂ ✓

Mass Grading & LMS Integration

Upload a ZIP of 400 scans. Every submission is parsed and checked for language equivalence against your reference solution — not visual similarity. Grades flow to Canvas, Moodle, or Blackboard over LTI; a full REST API covers everything else.

Export to Code

Every validated machine exports to clean JSON, Python, or C++ — plus JFLAP .jff for compatibility. Drop it straight into your codebase or courseware.

{ "type": "DFA", "states": ["q0", "q1", "q2"], "initial": "q0", "accepting": ["q2"], "transitions": { "q0": {"0": "q1", "1": "q0"}, … } }

Automated exam grading
